➊ ABOUT

マネープログラムとは

マネープログラムは、「お金の量」だけを追いかけるのではなく、お金・時間・健康・人間関係・仕事・幸せを一緒に考えながら、望む人生を実現するための習慣を身につける学びです。

目指すのは、「お金がないから」と大切なことを諦めない人生。

自分の現在地を数字で知り、人生の目的地から逆算して、今できる一歩を決める。そして「稼ぐ・使う・貯める・増やす・守る」を、実生活の中で少しずつ試します。

派手な近道を探すのではなく、焦らず、一段ずつ。未来を変えるのは一度の大きな決断より、今日から積み重ねる小さな習慣だと考えます。

➋ WHAT YOU LEARN

マネープログラムで学べる内容

知識で終わらせず、毎日の選択へ変えていくことが大切です。主な学びを、6つのテーマでご紹介します。

01

現在地を知る

収入・支出・貯金・投資・借入を整理し、今どこにいるのかを数字で確かめます。

02

人生から逆算する

10年後や人生の終わりにどんな毎日を送りたいかを描き、必要なお金と行動を考えます。

03

稼ぐ・使う・貯める

人に価値を届けて収入を得ること、満足度を下げずにお金を残すことを学びます。

04

増やす・守る

投資・金利・保険・税金・借入の基本を知り、焦らず長期で資産を育てます。

05

働き方を育てる

E・S・B・Iの働き方を理解し、今の仕事を大切にしながら未来の選択肢を広げます。

06

続く習慣をつくる

小さく試し、振り返り、改善する。自分に合う仕組みで、お金との良い関係を育てます。

➌ CHANGES

学びが、毎日の選択を変えていく

受講による変化は、急にお金が増えることだけではありません。自分の現在地を知り、未来から逆算し、続けられる行動を選べるようになること。その積み重ねが、人生の選択肢を育てます。

漠然とした不安から、見える現在地へ

収入・支出・資産・負債を整理することで、「何となく心配」を、具体的に扱える課題へ変えていきます。

BEFORE 02

知っている状態から、続けられる習慣へ

学んで終わらず、先取り・自動化・月1回の確認など、無理なく続けられる仕組みに落とし込みます。

BEFORE 03

お金中心から、人生中心の計画へ

お金・時間・健康・仕事・大切な人との関係を一緒に見つめ、自分にとっての豊かさから計画をつくります。

COLUMN 01

お金は目的ではなく、人生の選択肢を増やす道具

「いくら持つか」だけではなく、「そのお金で、どんな時間と人生を選びたいか」から考えます。〈詳しく読む〉

お金を増やすことだけが目的になると、いつの間にか、お金のために大切な時間や健康を使い続ける状態になりかねません。マネープログラムの考え方では、先に望む暮らしを描き、その実現に必要な手段としてお金を位置づけます。

たとえば、家族や大切な人と過ごす時間、学び直す時間、働き方を選べる余白、誰かを応援できる力。お金の価値は、数字そのものより、人生にどのような選択肢を生み出すかで変わります。

今日の一歩：「お金が十分にあったら増やしたい時間」を3つ書く。
COLUMN 02

不安を小さくする第一歩は、現在地を数字で見ること

漠然とした不安を、収入・支出・資産・負債という扱える情報へ変えていきます。〈詳しく読む〉

お金の不安は、金額が少ないことだけから生まれるとは限りません。「何にいくら使っているか分からない」「将来どのくらい必要か見えない」という、分からない状態そのものが不安を大きくします。

まずは毎月の収入と支出、預貯金、投資、借入を一枚にまとめます。良い・悪いと評価する必要はありません。現在地が分かれば、次に何を整えるかを自分で選べるようになります。数字は自分を責める材料ではなく、未来への地図です。

今日の一歩：通帳や明細を見て、収入・固定費・貯蓄・借入の4項目を書き出す。
COLUMN 03

10年後から逆算すると、今日の一歩が具体的になる

目先の節約だけでなく、望む未来から必要なお金と行動を考える方法です。〈詳しく読む〉

未来の計画は、今の延長だけで考えると小さくまとまりがちです。先に10年後の暮らし、働き方、健康、大切な人との時間を描き、そこから3年後、1年後、今月へと戻って考えます。

大きな目標を立てることが目的ではありません。「この行動は10年続けられるか」「今日の選択は望む未来につながっているか」と問い直せることが大切です。逆算すると、焦りではなく優先順位から行動を決められます。

今日の一歩：10年後の理想の1日を書き、そのために今月始めることを1つ決める。
COLUMN 04

知識を増やすより、続く経済習慣をひとつつくる

分かっているのに動けない状態から、意志の強さに頼らない仕組みへ進みます。〈詳しく読む〉

貯蓄や投資の知識があっても、毎月の行動に結びつかなければ暮らしは変わりません。必要なのは、たくさん学ぶことと同時に、学びを繰り返せる形へ変えることです。

収入日に自動で先取りする、月1回だけ家計を確認する、学んだことを小さく試す。行動のハードルを下げ、振り返り、改善する。その循環が、無理なく10年続く経済習慣を育てます。

今日の一歩：毎月同じ日に「お金の30分」を予定へ入れる。
COLUMN 05

「稼ぐ・使う・貯める・増やす・守る」を一緒に見る

一部分だけを頑張るのではなく、お金の流れ全体をバランスよく整えます。〈詳しく読む〉

収入を増やしても使い方が変わらなければ残りません。節約だけを続けても、人生の喜びまで小さくなることがあります。投資で増やすことを急ぎすぎれば、生活防衛やリスク管理が置き去りになります。

大切なのは、5つの働きを別々に考えないこと。価値を届けて稼ぎ、納得して使い、未来へ貯め、長期で増やし、大きな損失から守る。今の自分に最も必要な一つから整えることで、全体が少しずつ安定します。

今日の一歩：5つのうち、今いちばん整えたいものを1つ選ぶ。
COLUMN 06

E・S・B・Iを知り、時間に依存しない収入を育てる

今の仕事を大切にしながら、収入の生まれ方と未来の選択肢を見直します。〈詳しく読む〉

Eは雇用されて働く人、Sは自分の技能や事業で働く人、Bは仕組みやチームを通じて価値を届ける人、Iは資産に働いてもらう人という見方です。どれが正解という話ではなく、自分の収入が何に支えられているかを理解するための地図です。

働いた時間に応じて得る収入は、生活を支える大切な土台です。そのうえで、商品、仕組み、チーム、資産など、一度の行動が繰り返し価値を生む形を育てると、時間と人生の選択肢が広がります。

今日の一歩：現在の収入をE・S・B・Iに分け、今後育てたい領域を決める。
COLUMN 07

増やす前に、暮らしを守る土台を整える

生活防衛資金・保険・税金・負債を確認し、焦らず資産形成を続けられる状態をつくります。〈詳しく読む〉

資産形成では、増やす方法に目が向きやすいものです。しかし、急な病気や収入減、家電の故障などが起きたとき、すぐに投資を崩したり借入を増やしたりすれば、長期計画が揺らぎます。

まず生活防衛資金を持ち、保険の目的、税金、返済条件、契約上のリスクを把握します。守りがあるからこそ、短期の値動きに振り回されず、長期・分散・継続の考え方で資産を育てられます。

今日の一歩：もしものときに必要な生活費1か月分を計算する。
COLUMN 08

時間は命。お金と一緒に整える

未来の資産だけでなく、今日の健康や大切な人との時間も豊かさとして考えます。〈詳しく読む〉

お金は増やせても、過ぎた時間を買い戻すことはできません。将来の安心をつくるために働きながら、現在の健康や大切な人との関係を失ってしまえば、本来望んでいた豊かさから離れることがあります。

お金の計画と同じように、どんな時間を増やしたいかを決めます。緊急ではないけれど重要な健康、学び、人間関係を先に予定へ置く。お金と時間の両方を自分で選べる状態が、経済的な自由の大切な意味です。

今日の一歩：来週の予定に「守りたい時間」を30分だけ先に入れる。
COLUMN 09

一人で抱えず、仲間と振り返る

習慣を続ける力を、意志の強さだけではなく、安心して話せる環境から育てます。〈詳しく読む〉

お金の悩みは、人に話しにくいテーマです。自分だけで解決しようとすると、不安や失敗を抱え込み、振り返る機会を失うことがあります。助けを求めることは、依存ではなく、次の一歩を選ぶ力の一つです。

伴走者や仲間と現在地を確認し、できたことを認め、うまくいかなかった理由を一緒に考える。責められずに学べる環境があると、知識は行動へ、行動は習慣へと変わりやすくなります。

今日の一歩：お金や未来について安心して話せる相手を1人思い浮かべる。
COLUMN 10

豊かさを自分だけで終わらせない、All-WINという考え方

自分の成功だけでなく、家族・仲間・関わる人へ価値が循環する状態を目指します。〈詳しく読む〉

自分が我慢し続ける成功も、誰かの犠牲の上に成り立つ利益も、長くは続きません。マネープログラムから読み取れる豊かさは、自分自身を大切にしながら、周囲の幸せにもつながるAll-WINの状態です。

経済的な余白が生まれると、時間を分かち合う、学びを伝える、誰かの挑戦を応援するなど、選べる行動が増えます。お金・時間・幸福が調和し、得た知恵が次の人へ渡っていく。そこに、資産額だけでは測れない豊かさがあります。

今日の一歩：自分が豊かになることで、笑顔にしたい人を3人書く。
